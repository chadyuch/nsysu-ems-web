# 中山大學雲端能源管理系統

供服務建議書簡報與操作展示使用的前端示範網站，含中山大學校徽、五個功能頁及可互動的示範資料。


## GitHub 公開網站

- 網站：https://chadyuch.github.io/nsysu-ems-web/
- 程式庫：https://github.com/chadyuch/nsysu-ems-web
- `main` 保存前端原始程式、操作說明與驗證程式。
- `gh-pages` 根目錄是 `dist` 的發布內容，透過 GitHub Pages 提供網站。

更新 `dist` 並提交至 `main` 後，在此程式庫執行以下指令，即可更新公開網站：

```console
git push origin main
git subtree split --prefix dist -b gh-pages
git push origin gh-pages
```

公開網址可以直接分享；GitHub Pages 並非提供專屬固定 IP 的主機。

## 開啟方式

直接用 Chrome 或 Edge 開啟 `dist/index.html`。網頁、字型替代方案與校徽皆可在本機使用，無須安裝套件或連接資料庫。

需要以網址啟動時，在專案目錄執行：

```console
python -m http.server 8793 --bind 127.0.0.1 --directory dist
```

瀏覽 `http://127.0.0.1:8793`。停止伺服器時按 Ctrl+C。

## 建議展示流程

1. 從首頁查看供電說明，按「字體再放大」體驗大字模式。
2. 將示範情境切換為停電，再到「太陽能與備用電力」查看保留供電範圍。
3. 切回平常供電，到「省電與供電設定」設定兩組電池上下限、契約容量及啟動百分比；展開試算查看影響，確認後儲存。
4. 到提醒頁記錄「已安排處理」。此動作不會把設備故障直接判定成已恢復。
5. 點右上角「切換示範角色」，選擇數據管理員或能源管理員，確認操作範圍與帳號管理限制。
6. 使用「重設示範資料」回到初始畫面。手機版可在導覽下方找到操作說明與重設入口。

## 場域與資料設定

### 電池電量與需量設定

SoC 就是電池還剩多少電，像手機的電量百分比；50% 表示大約還有一半電，不等於剩餘使用時數。供電下限表示用到多少就停止電池供電；充電上限表示充到多少就停止繼續充電。

| 設定 | 初始示範值 | 用途 |
| --- | --- | --- |
| 平常有台電：併聯供電下限 | 30% | 保留部分電量，不再繼續支援平常用電 |
| 平常有台電：併聯充電上限 | 80% | 達到後停止繼續充電 |
| 台電停電：孤島供電下限 | 10% | 容許多用一些電支援必要用電，達到後交由現場安排其他電源 |
| 台電停電：孤島充電上限 | 95% | 有太陽能等電力可充時，容許多存一些電 |
| 契約容量 | 1,000 kW | 依學校與台電的契約資料填寫 |
| 啟動儲能百分比 | 90% | 最新需量達 900 kW 時符合啟動門檻 |

以上均為展示用數字，不是校方核定值。本示範 SoC 可設定 10%～95%，不代表設備通用安全範圍。每組下限必須低於上限；孤島下限必須低於併聯下限，孤島上限必須高於併聯上限。停電時範圍較寬，是為了讓更多電量可用於重要設備；提高上限不會立即增加現有電量，仍要有電可充，也需要時間。

啟動門檻＝契約容量 × 啟動百分比。畫面即時計算並保留最多兩位小數；最新需量大於或等於門檻，且 SoC 高於併聯下限時，才符合啟動條件。契約容量須填正整數，啟動百分比為 1%～100%。容量設定只供 EMS 判斷，不會變更台電契約。

需量應來自同一計費總電表的最新回報或估算值；台電計費需量以 15 分鐘平均為基礎，不能拿全校瞬間總負載直接代替。實際輸出功率仍由現場依供需、電池與設備限制決定。

獨立試算可切換併聯／孤島、電池剩餘比例與測試需量。試算不改變供電情境或現場設備；孤島運轉不使用契約需量門檻。選用「優先保留備用電」時，平常暫停需量支援，兩組電量範圍仍保留，停電後依孤島範圍支援。

六項設定須先檢查、再確認才儲存，會留下操作紀錄。數據管理員只能閱讀與獨立試算；系統管理員、能源管理員可儲存。停電或資料中斷時暫停送出新設定。舊版單一保留值與提醒值已由上述新設定取代；既有帳號與提醒紀錄保留。

### 總覽提醒與功能範圍

所有設備提醒均限於微電網設備：儲能電池、PCS（電力轉換設備）、太陽能與柴油發電機。總覽、提醒中心、提醒詳細資料及 CSV 匯出採相同設備範圍，不呈現教室用電、水表、照明或其他一般校園設備提醒。

「先看這些提醒」及總覽提醒件數只計入尚未恢復的微電網設備異常；已安排處理仍保留，確認恢復後才不再列出。提醒中心可查閱尚未處理、已安排處理與已恢復紀錄，每筆均顯示設備名稱。示範包含電池溫度偏高、PCS 通訊中斷、太陽能轉換設備異常及已恢復的柴油機啟動電池提醒。

重新開啟網站時，舊版教室與水表提醒會自動排除；已保存的微電網處理紀錄、帳號與供電設定保留，不必重設所有資料。原有電池室溫度事件會辨識為儲能設備紀錄；不同設備的舊處理文字不會套用到新事件。

已移除「設備與使用時間」導覽、頁面與相關開關、溫度、排程操作。統計報表中的場域、空間、設備篩選仍保留，供查看歷史資料。

### 統計報表操作

進入「統計報表」，選擇報表，再選擇範圍與時間，按「查詢報表」或「查詢孤島事件」。更改條件後會暫停匯出，直到查詢完成，確保下載檔與結果相符。

| 報表 | 可選條件 | 圖表與匯出 |
| --- | --- | --- |
| 用電報表 | 場域、空間、用電設備 | 用電量長條圖；較長期間採折線圖；下載統計 CSV |
| 發電量報表 | 場域、太陽能／柴油發電機、指定設備 | 發電量比較圖；下載分項與合計 CSV |
| 儲能運轉報表 | 場域、儲能設備、充電／放電／SoC | 充放電比較圖與獨立 SoC 折線圖；下載充放電及期初、最低、最高、期末電量 |
| 異常告警報表 | 微電網場域、儲能電池／PCS／太陽能／柴油機、指定設備、異常類型、提醒程度 | 各時段事件數圖、異常分類數、事件明細；分別下載統計與事件明細 CSV |
| 孤島運轉資訊 | 日期範圍、一次孤島事件、事件中的時間點 | 事件時間軸、電池功率與 SoC、柴油機功率與剩餘油量、太陽能全程功率；下載事件摘要與完整數據 CSV |

前四類提供小時、日、月、年報表，對應整點日期時間、日期、月份與年份的起訖選擇。範圍兩端皆納入。明細每頁 12 筆，CSV 會下載全部紀錄，不受分頁影響。「列印這頁」列印目前顯示的頁面。

報表採固定示範歷史，資料範圍為 **2024/1/1 至 2026/10/6 23:59**。2026 年及 2026 年 10 月只計至截止日，結果會標示期間尚未完整。無效日期、起訖顛倒及超出資料範圍均會提示修正。

用電示範涵蓋國研、管理學院、社科院、A 水池及海工停車場，依不重複的設備電量加總。2026/10/6 原四個區域合計為 8,380 度，海工停車場另計 1,100 度。空間與新增設備迴路是示範配置，水表用水數值不列為用電量。

SoC 為電池剩餘比例，不能加總。儲能教學模型採 3,000 度容量且暫不計損耗；每小時充放電與 SoC 變化一致，日／月／年保留期間最低、最高、期初及期末值。異常報表以固定的唯一歷史事件與發生時間計數，與日常提醒頁的處理待辦分開。

### 孤島運轉資訊

先輸入日期範圍，再選擇事件開始時間，即可閱讀整次事件。查詢包含與日期範圍重疊的事件，因此搜尋跨日事件的第二天，也能找到前一天開始的孤島運轉。日期使用 **YYYY/MM/DD**，時間使用 **hh:mm:ss**。

提供三筆獨立演練資料：2026/10/06 日間由電池轉交柴油機、2026/09/28 至 2026/09/29 夜間跨日，以及 2026/09/18 短暫停電而未啟動柴油機。這些事件沒有併入其他一般統計報表，也不代表實際停電紀錄。

事件時間軸標出進入孤島、電池開始供電、柴油機啟動準備、柴油機接手與電池停止、恢復併網，以及柴油機冷卻完成後停機。柴油機「停止供電」與「停止運轉」分別記錄；未啟動時清楚顯示「本次未啟動」。點選「查看這一刻的數值」或時間選單，可同步查看五張圖上的位置與數值。

五張圖採相同時間範圍，包含恢復台電供電後的冷卻與停機紀錄。電池剩餘電量依 3,000 度容量與 95% 示範放電效率計算；油量以剩餘百分比呈現。夜間太陽能為零；日間長事件示範柴油機接手後暫停太陽能、恢復併網後重新發電。功率、電量與油量使用同一組紀錄，完整數據 CSV 包含所有時間點。

### 彩色動態能源流向

兩處圖表均以左側設備、右側「國研大樓微電網迴路用電」的方式呈現，右側用電端與電力來源保持同一排。停電及低電量情境另在用電端列出目前保留的用電範圍。窄螢幕與大字模式維持相同方向，可在圖內左右滑動，或按「看電力來源」「看用電端」查看，文字保持原有大小。

「電從哪裡來？」與「目前供電的方式」使用相同的能源流向圖。台電用藍色、太陽能用金褐色、柴油機用紫色，各有獨立供電路徑；儲能另分綠色放電路徑與桃紅色充電路徑。箭頭、白話狀態及 kW 數字一起呈現，灰色虛線表示沒有電力流動。太陽能數字延續國研屋頂與海工停車場的合計範圍。

可切換「模擬電池充電」查看箭頭朝電池流動：台電 260 kW 加上太陽能 360 kW，供應設備用電 520 kW 並為電池充電 100 kW。切換「模擬用電偏高」或「模擬台電停電」，可看到綠色路徑從電池向外供電。單一情境不會同時充電與放電；電池欄位以負數記錄充電、正數記錄放電，介面分開顯示兩個正值與明確方向。

數值為固定示範時點，動畫只表示方向，速度不表示電力大小。零功率的路徑不播放動畫；連線中斷時停止所有流動並標示最後資料。所有角色都能暫停或繼續觀看動畫，此項偏好僅影響顯示，並在重新開啟後保留。若裝置設定減少動態效果，則使用固定箭頭。

### 供電示範

太陽能採國研屋頂 135 kWp、海工停車場 295 kWp 的更新規劃；電池容量至少 3,000 kWh、供電能力至少 1,200 kW；既有柴油發電機 400 kW，充電區共 6 座設備。既有躉售太陽能 51.92 kWp 與未來風雨球場規劃未計入自用供電合計。

停電情境僅示範國研重要用電及指定必要設備；電池不足情境縮減為國研必要用電 240 kW。所有情境均滿足電源提供等於設備用電加上電池充電、且不超過所採設備能力。停電期間暫停送出新的供電設定。

用電量、面積、設備名稱與位置細節、溫度、健康度、角色、人名及操作回報皆為示範。四個區域的固定歷史紀錄與情境切換分開標示，不表示完整校園清冊或即時量測。連線中斷時顯示最後資料並暫停送出新設定。

示範狀態儲存在目前瀏覽器的 localStorage。這是前端操作展示，尚未串接電表、現場控制器、實際帳號登入、郵件或簡訊通知、備份服務與安全檢測。頁面中的安全工作以待正式驗證標示；角色限制不能取代正式後端的身分與授權驗證。

| 功能 | 系統管理員 | 數據管理員 | 能源管理員 |

| 查看數據、篩選查詢、五類統計報表 | 可使用 | 可使用 | 可使用 |
| 匯出報表、提醒與操作紀錄 | 可使用 | 可使用 | 可使用 |
| 查看供電狀態、提醒與現有設定 | 可使用 | 可使用 | 可使用 |

| 新增或修改提醒處理紀錄 | 可操作 | 不可操作 | 可操作 |

每頁顯示目前角色及操作範圍。數據管理員的設定控制會停用，但查詢條件、明細選擇、圖表與匯出仍可操作。非系統管理員進入「使用者與權限」時，只顯示權限說明，不提供帳號管理表單。所有角色都可調整自己的字體大小。

既有本機示範帳號保留：林管理員為系統管理員、王維護員為能源管理員、陳研究員為數據管理員；原有新增帳號也沿用其相對應角色。新增帳號預設為數據管理員。失效或停用帳號不會自動取得系統管理員權限。

變更操作在介面及執行處理時均檢查角色；確認操作綁定發起者，關閉確認窗或切換角色即取消尚未送出的操作。停電、資料中斷與重要設備保護等既有操作條件仍適用。

右上角的角色切換是展示用工具，供體驗三種角色，不會修改帳號權限，也不是正式登入。本版為前端示範；正式系統須由後端逐項驗證身分與授權，不能把瀏覽器中的狀態視為安全邊界。

## UI／UX 設計

依 UI UX Pro Max 的可讀性、對比、鍵盤操作與響應式建議，針對 60 歲以上、無微電網背景的使用者調整：

- 內文預設 20 px，可切換為 24 px；次要文字至少 18 px，圖表數字隨版面重排。
- 使用明亮底色、深色文字與清楚的卡片分區；狀態同時用文字說明，不只靠顏色。
- 按鈕至少 48–50 px，提供可見的鍵盤焦點；彈窗可按 Escape 關閉。
- 用「電池還有多少」「電從哪裡來」「用到多少就停」等白話文字，必要單位附簡短解釋。
- 變更前先說明影響，送出後顯示結果；保護重要研究設備，避免誤操作。
- 校徽按原比例呈現，網站名稱為「中山大學雲端能源管理系統」。

- `dist/app.js`：五個功能頁、互動、角色權限、匯出與本機儲存。
- `dist/settings-data.js`：兩組 SoC 範圍、契約需量門檻、驗證與獨立試算模型。
- `dist/settings-ui.js`、`dist/settings.css`：設定表單、白話說明、範圍圖、試算、錯誤提示及確認儲存。
- `dist/reports-data.js`：固定逐時資料、場域／空間／設備關係、四類統計與時間彙整。
- `dist/reports-ui.js`、`dist/reports.css`：報表查詢、統計圖、明細分頁與匯出。
- `dist/island-data.js`：三次孤島演練事件、切換時刻及功率／電量／油量紀錄。
- `dist/island-ui.js`、`dist/island.css`：孤島事件查詢、時間軸、五張圖表、明細與 CSV 匯出。
- `tests/verify_flow.py`：六種情境、流向與實際動畫、充放電互斥、停止與暫停、減少動態效果、跨頁一致性及大字版面。
- `tests/verify_frontend.py`：獨立的無頭瀏覽器測試。
- `tests/verify_reports.py`：四類報表 × 四種時間單位、篩選、錯誤處理、完整匯出及大字版面。
- `tests/reports-model.test.cjs`：層級加總、跨時間彙整、閏日、設備容量、SoC 能量平衡與告警唯一性。
- `tests/island-model.test.cjs`：孤島切換時序、供需平衡、SoC 與油量變化、夜間零發電及跨日查詢。
- `tests/verify_island.py`：三次事件、兩種匯出、日期篩選、時間點查看、五頁籤鍵盤操作及大字版面。
- `tests/verify_roles.py`：三種角色的允許／拒絕操作、直接操作處理與表單提交檢查、確認窗取消、失效帳號、五類報表匯出及大字版面。
- `tests/settings-model.test.cjs`：數值、上下限、門檻等號邊界、兩種模式與備援策略判斷。
- `tests/verify_settings.py`：設定確認與保存、錯誤定位、獨立試算、角色限制、功能移除、總覽設備異常篩選及大字版面。
- `tests/verify_microgrid_alerts.py`：提醒設備範圍、舊資料更新、處理紀錄保留、各入口與匯出一致性，以及 PCS 告警報表。

測試需要 Python、Playwright 與 Chrome，並先啟動上述本機伺服器：

```console
python tests/verify_frontend.py
python tests/verify_flow.py
python tests/verify_reports.py
node tests/reports-model.test.cjs
node tests/island-model.test.cjs
python tests/verify_island.py
python tests/verify_roles.py
node tests/settings-model.test.cjs
python tests/verify_settings.py
python tests/verify_microgrid_alerts.py
```

測試涵蓋資料加總、六種供電情境、操作確認、電池與需量設定、提醒處理、停用帳號、查看權限、CSV 匯出，以及 375／768／1024／1440 px 的五頁大字版面。測試輸出與截圖存於 `.qa/`，不部署到網站。

網站另有功能偵測式的 WebMCP 示範狀態查詢與情境切換介面；一般瀏覽器無此能力仍可完整操作。目前環境未提供可驗證 WebMCP 的瀏覽器，因此未宣稱該介面已通過相容性驗證。
